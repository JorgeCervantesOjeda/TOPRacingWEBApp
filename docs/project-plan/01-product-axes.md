# Product Axes

El proyecto tiene cuatro ejes funcionales:

- identidad: login, logout, alta, confirmacion de correo, recuperacion de password
- competidores: participantes, autos, perfiles y ownership
- competencia: regattas, penalties, pointscounts, registrations
- territorio: venues y jerarquias geografico-administrativas

Prioridad de producto:

1. identidad y acceso
2. alta y edicion de participante
3. consulta publica de welcome y contenido abierto
4. operacion autenticada del resto del dominio

Principio de alcance:

- lo publico debe ser minimo y claro
- lo operativo debe requerir autenticacion valida
