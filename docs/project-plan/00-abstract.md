# Abstract

TOPRacingWEBApp debe consolidarse como una aplicacion web estable para operar la liga TOP-Racing.

Objetivo central:

- permitir que participantes y administradores usen los flujos principales sin bloqueos operativos.

Resultados esperados:

- acceso consistente a login, welcome y zonas protegidas
- alta, confirmacion y mantenimiento de participantes
- operacion confiable de regattas, venues, cars y registrations
- despliegue repetible sobre GlassFish 6+

Estrategia general:

1. estabilizar
2. endurecer reglas de acceso y navegacion
3. simplificar operacion local y despliegue
4. refactorizar solo despues de recuperar confiabilidad
