# Writing Method

Este documento fija la metodología de escritura para el paper fundacional y los papers derivados.

## Regla general

La escritura se hará por capas transversales a todo el paper.

No se trabajará una sección hasta volverla casi final antes de pasar a la siguiente.

En cambio, se seguirá este orden:

1. construir el esqueleto completo
2. llenar cada sección con ideas abstractas muy breves
3. agregar una nueva capa de detalle en todas las secciones
4. repetir el proceso, bajando gradualmente del nivel abstracto al nivel concreto

## Principio central

La abstracción debe bajar de manera transversal al documento completo.

Eso significa:

- primero tener todo el mapa del paper
- después una versión mínima de cada sección
- luego una versión más precisa de cada sección
- luego una versión más formal de cada sección
- luego una versión más concreta de cada sección

La idea no es reescribir estilísticamente lo mismo.

La idea es aumentar la resolución conceptual y formal del documento.

En cada iteración se deben agregar elementos un poco más concretos que los ya escritos, sin saltar prematuramente al nivel más concreto posible.

## Secuencia de trabajo

### Capa 1. Esqueleto

Solo se fija:

- título tentativo
- secciones
- subsecciones
- propósito de cada parte

### Capa 2. Ideas abstractas breves

Cada sección recibe:

- una o dos ideas centrales
- lenguaje natural
- formulación todavía general

### Capa 3. Intuición refinada

Cada sección recibe:

- mejor articulación conceptual
- relaciones entre ideas
- tensiones o problemas que la sección aborda
- primeros elementos intermedios entre lo abstracto y lo formal

### Capa 4. Formalización inicial

Cada sección recibe, cuando aplique:

- definiciones
- variables
- axiomas
- proposiciones preliminares

### Capa 5. Descenso hacia lo concreto

Cada sección incorpora:

- ejemplos
- interpretaciones
- implicaciones
- conexiones con el dominio de aplicación

Este descenso hacia lo concreto debe hacerse de manera gradual.

No se busca escribir de inmediato la versión más concreta de una sección, sino insertar niveles intermedios de precisión que conserven continuidad con la capa anterior.

### Capa 6. Consolidación

Se revisa:

- coherencia global
- consistencia terminológica
- progresión entre secciones
- balance entre intuición y formalidad

## Regla de estilo

Cada sección debe poder crecer sin perder claridad.

Por ello, en cada iteración conviene preservar este patrón:

1. intuición
2. formalización
3. implicación

## Regla de control

Antes de profundizar una sección, debe verificarse que el resto del paper ya tenga la misma capa de desarrollo o una capa compatible.

Esto evita:

- sobredesarrollar una sola parte
- perder la arquitectura global
- introducir formalización prematura en una sección aislada
- saltar desde una formulación abstracta a una formulación excesivamente concreta sin pasos intermedios

## Criterio de avance

Se considera que una capa está terminada cuando todas las secciones del paper ya contienen un desarrollo del mismo nivel de abstracción.

## Aclaración metodológica

Este método debe entenderse como una estrategia de incremento gradual de resolución semántica.

Por lo tanto:

- no consiste en reescritura estilística
- no consiste en pulir una sola sección hasta casi terminarla
- no consiste en brincar directamente desde lo abstracto hasta lo más concreto

Sí consiste en:

- partir de una formulación general
- añadir capas sucesivas de precisión
- introducir elementos intermedios de concreción
- conservar continuidad conceptual entre una versión y la siguiente
