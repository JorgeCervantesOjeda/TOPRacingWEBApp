# Open Decisions

Decisiones funcionales pendientes:

1. si el alta de cuenta debe seguir disponible para anonimos
2. si confirmacion de correo y reset de password deben ser publicos
3. que vistas, si alguna, deben seguir siendo publicas ademas de welcome

Decisiones tecnicas pendientes:

1. si conviene agregar pruebas automatizadas de flujos HTTP
2. si el envio de correo debe resolverse con OAuth actual o con otro mecanismo
3. si algunas reglas de acceso deben moverse de controller a servicios
