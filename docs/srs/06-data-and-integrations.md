# Data And Integrations

Datos principales:

- Participant
- Car
- Venue
- Registration
- Regatta
- jerarquias territoriales

Integraciones:

- MySQL para persistencia
- GlassFish como runtime
- correo saliente para confirmacion y notificaciones

Dependencia visible:

- sin credenciales OAuth de correo, la confirmacion puede generarse pero no enviarse automaticamente
